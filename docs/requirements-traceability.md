This matrix maps every product requirement and shared baseline requirement to its proposed architecture, implementation work package, and acceptance evidence. It is a planning artifact, not evidence that the requirements already pass. All rows are initially **Not verified**. Update the matrix with PR/test/report links as implementation progresses. Musts cannot be dropped to recover time; defer Should/Could according to the SRS.
